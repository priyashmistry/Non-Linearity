# Veloce Detector Non-linearity Analysis

This repository contains the simulation and analysis software used to investigate detector non-linearity in Veloce flat-field observations. It supports two complementary approaches:

1. the conventional photon-transfer-curve (PTC) method; and
2. an exposure-ratio method based on the mean response of matched flat-field exposures.

The repository also contains representative simulated CCD datasets and the results obtained by applying both methods under different detector configurations.

## Repository contents

* [`CCD Simulation.ipynb`](./CCD%20Simulation.ipynb): generates synthetic Veloce-like échelle flat-field observations.
* [`vnonlin.py`](./vnonlin.py): performs the PTC and exposure-ratio analyses.
* [`Mask/region_mask_mask.fits`](./Mask/region_mask_mask.fits): detector mask defining the illuminated échelle-order regions used by the analysis.
* [`Simulated Data/`](./Simulated%20Data/): representative simulated flat-field datasets and their analysis products.

## Simulated datasets

The `Simulated Data` directory contains four simulation sets:

```text
Simulated Data/
├── 111111/
├── 111112/
├── 111113/
└── 111114/
```

Each simulation directory contains:

```text
0_1/
1_0/
Output_Figs/
```

Here:

* `0_1` contains the short-exposure simulated flat-field frames;
* `1_0` contains the corresponding long-exposure frames; and
* `Output_Figs` contains figures, fitted curves and numerical products generated by the analysis.

The four datasets represent different combinations of intrinsic detector response and charge sharing. The precise configuration associated with each dataset should be read from the corresponding simulation settings used in `CCD Simulation.ipynb`.

Only representative simulated FITS files may be included in the repository because the complete regenerated datasets are large. The full datasets can be reproduced using the simulation notebook and the stated parameters and random seeds.

## Generating simulated CCD data

The [`CCD Simulation.ipynb`](./CCD%20Simulation.ipynb) notebook generates Veloce-like CCD flat-field frames.

The simulation includes:

* Veloce-like detector dimensions;
* curved échelle-order morphology;
* spatially varying illumination;
* photon noise;
* Gaussian read noise;
* optional signal-dependent charge sharing;
* optional intrinsic detector non-linearity;
* short- and long-exposure image sequences; and
* fixed random seeds for reproducibility.

Before running the notebook, review the configuration section near its beginning. In particular, check:

* output directories;
* exposure times;
* number of simulated frames;
* random seed;
* detector gain;
* read noise;
* charge-sharing switch and parameters;
* intrinsic non-linearity switch and coefficients; and
* saturation level.

The current charge-sharing prescription uses the parameters

```text
f_min = 0.001
f_max = 0.1
M_0   = 40000 ADU
w     = 10000 ADU
r     = 0.6
```

The intrinsic non-linearity simulation uses

```text
a_1 = 1
a_2 = -5 × 10^-7
a_3 = 1 × 10^-12
```

Users should confirm that these settings match the intended simulation case before generating new data.

## Running the analysis

The [`vnonlin.py`](./vnonlin.py) script applies both the PTC and exposure-ratio methods to matched short- and long-exposure directories.

The general command is:

```bash
python vnonlin.py PATH_TO_0_1 PATH_TO_1_0
```

For example:

```bash
python vnonlin.py \
  "Simulated Data/111111"
```

Paths containing spaces must be enclosed in quotation marks.

## Analysing simulated data

When analysing the supplied simulated datasets, include the `--dm` option:

```bash
python vnonlin.py \
  "Simulated Data/111111" --dm
```

The `--dm` option indicates that the analysis is being applied to simulated data and prevents the detector mask from being generated again. The existing mask and simulated-data handling are used instead.

The command can be repeated for each simulation:

```bash
python vnonlin.py \
  "Simulated Data/111112" \
  --dm

python vnonlin.py \
  "Simulated Data/111113" \
  --dm

python vnonlin.py \
  "Simulated Data/111114" \
  --dm
```

Run the following to display all currently supported command-line options:

```bash
python vnonlin.py --help
```

## Non-linearity metric

The detector response is summarised using the endpoint metric

$$
\mathrm{NL}_{\max}(\%) =
\frac{F(x_0)-F(x_{\max})}{F(x_0)}
\times 100,
$$

where \(F(x)\) represents the fitted gain for the PTC method or the fitted normalised ratio for the exposure-ratio method.

The adopted reference levels are:

```text
x_0   = 5000 ADU
x_max = 62000 ADU
```

These values should remain consistent between the simulation, analysis code, figures and manuscript.

## Output products

Depending on the selected options, `vnonlin.py` produces:

* PTC variance–mean plots;
* fitted signal-dependent gain curves;
* exposure-ratio density plots;
* binned exposure-ratio measurements;
* fitted ratio curves;
* fit residuals;
* normalisation diagnostics;
* estimated \(\mathrm{NL}_{\max}^{\rm PTC}\);
* estimated \(\mathrm{NL}_{\max}^{\rm exp}\); and
* CSV files containing fitted curves or numerical results.

Outputs are written to an `Output_Figs` directory associated with the analysed dataset.

## Software requirements

The analysis requires Python 3 and commonly used scientific Python packages, including:

```text
numpy
scipy
pandas
matplotlib
astropy
scikit-learn
statsmodels
```

Install the dependencies using the repository environment or requirements file when supplied. Alternatively:

```bash
python -m pip install numpy scipy pandas matplotlib astropy \
  scikit-learn statsmodels
```

A dedicated virtual or Conda environment is recommended.

## Reproducibility

To reproduce the reported simulation results:

1. clone this repository;
2. install the required Python packages;
3. inspect the parameters and random seeds in `CCD Simulation.ipynb`;
4. generate the required short- and long-exposure datasets;
5. run `vnonlin.py` on the corresponding `0_1` and `1_0` directories using `--dm`; and
6. compare the generated results with those provided in each `Output_Figs` directory.

The simulation configurations, signal endpoints, mask and random seeds should not be changed when reproducing the manuscript results.

## Large-file storage

FITS files are managed using Git Large File Storage (Git LFS). After cloning the repository, ensure that Git LFS is installed:

```bash
git lfs install
git lfs pull
```

Without Git LFS, the downloaded FITS files may appear only as small pointer files rather than valid astronomical images.
